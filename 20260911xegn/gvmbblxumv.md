# “323”攻坚行动：宜昌市脑心健康管理专科联盟成立

> 更新时间：2026-09-11 (UTC+8)

宜昌市脑心健康管理专科联盟成立

**医防融合护心脑健康**

**湖北省 / “323”攻坚行动******

10月12日，宜昌市脑心健康管理专科联盟成立大会在宜昌市中心人民医院举办，会上为118家联盟成员单位授牌。联盟的成立，旨在落实湖北省“323”攻坚行动，推进医防融合，整合全市脑心健康管理师资源，提升我市卒中健康管理水平。

此次会议由宜昌市影响群众健康突出问题管理办公室、宜昌市卒中防治中心主办，来自全市各县市区的118家卒中中心、防治中心、基层卒中防治站、脑心健康管理师共150多人参加。

湖北省卒中防治中心办公室主任彭小祥、湖北省第三人民医院脑卒中防治中心办公室健康管理组组长戚璐、宜昌市中心人民医院副院长赵卫民、宜昌市卫健委基层卫生科科长任晶晶、宜昌市中心人民医院护理部主任席祖洋等出席会议并致辞。

脑心健康管理

脑心健康管理是维护人民群众健康的重要手段，也是当前医疗卫生工作的探索的新领域。近年来，随着人口老龄化的加剧以及生活方式的改变，脑心疾病的发病率呈逐年上升趋势，给患者家庭和社会带来了沉重的负担。在这一严峻形势下，脑心健康管理工作显得尤为重要，可以对脑卒中高危患者进行全方位，全周期、全生命流程进行系统管理，降低脑卒中的发病率和复发率，体现以治病向防病、防治结合观念的转变。

**湖北省 / “323”攻坚行动******
脑心健康管理师联盟的成立，是脑心健康管理师培训体系建设的重要环节，为各地的脑心健康管理师们搭建了一个交流合作、共同进步的平台。通过这个平台，大家可以分享经验、探索脑心健康管理工作方法，为提高脑血管疾病的防治水平群策群力。宜昌市中心人民医院作为盟主单位，将努力为大家创造培训和学习机会，为各成员单位做好协调和服务工作。
