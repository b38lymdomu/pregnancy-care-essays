# 垂体泌乳素高能什么形成

> 更新时间：2026-09-17 (UTC+8)

人体内的激素可以维持人体的健康，一旦激素出现异常，可能会导致身体的某个部位出现异常，就像是垂体泌乳素，虽然不是不是很重要，但是过高也不行。那么，垂体泌乳素高能形成什么，还有泌乳素高怎么治疗?
垂体泌乳素高能什么形成
　　泌乳素在女性孕晚期和哺乳期都会比较高，这样可以促进乳腺分泌乳汁，宝宝才能得到充足的奶水，但是泌乳素过高对妈妈是不利的。那么，垂体泌乳素高是怎么造成的?

　　1、神经刺激。身体的某些部位受到刺激，尤其是胸部皮肤，胸部周围的神经受到损伤会引起剧痛，从而会把这种刺激传递到神经系统，然后传递到下丘脑导致泌乳素升高。

　　2、药物因素。泌乳素高受到多种因素的影响，某些药物也会泌乳素的分泌产生影响，导致泌乳素高。此外，剧烈的活动和外伤等也会造成泌乳素分泌增多。

　　3、垂体障碍。这种情况主要是因为垂体部位出现肿瘤引起的。此外，垂体功能亢进也会导致女性泌乳素升高，甚至出现闭经的情况。

　　4、原发性甲状腺功能减退。当甲状腺出现功能减退，分泌不足时，信息会传递到下丘脑，从而分泌出大量的甲状腺激素开释因子。这种因子会刺激垂体分泌大量的泌乳素，从而导致出现溢乳的现象出现。

　　5、下丘脑障碍。女性下丘脑出现问题或是附近病变，都会导致泌乳素因子的分泌减少，或者是促甲状腺激素开释因子和泌乳素开释因子增多。泌乳素失去一定的抑制从而大量分泌，从而引起女性体内的泌乳素过高。

　　有不少的女性对于泌乳素并不是很了解，当出现泌乳素过高时也不知情。要知道，泌乳素是脑垂体分泌的一种激素，在女性孕期和哺乳期分泌比较旺盛，从而促进乳腺的发育和泌乳。泌乳素含量过高，容易出现高泌乳素血症，对女性有一定的影响。所以，多了解一点导致泌乳素高的因素是很有必要的，提前做好预防工作。
泌乳素高怎么治疗
　　1.药物治疗是第一选择：患有垂体泌乳素微腺瘤的未生育妇女通常可以口服多巴胺激动剂治疗，据报道，过半的的妇女可以在2个月后怀孕。经过长期治疗，肿瘤体积可缩小，一些患者可以治愈。年轻女性可能在妊娠期间治疗后患垂体腺瘤的概率会明显增大，如果到了特殊时期，需按实际情况考虑是否要进行手术。

　　2.经鼻蝶手术：如果患者对药物敏感，那么手术是最根本的治疗方法。手术成功的关键在于操作者的经验、肿瘤的体积和侵袭性的存在，半数以上的患者在术后泌乳素水平达到正常。因此，患者选择手术治疗是合理的。

　　3.随访观察：数据显示，只需一点点泌乳素微腺瘤就能够发展成更大的肿瘤。因此，对于患上肿瘤的患者，如果患者月经周期和性欲正常，而且乳汁分泌较少，还没有准备怀孕，可以先不急着治疗，可随诊观察。
